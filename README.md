# code

Planning workspace for a personal, cross-platform agentic coding system built around a deeply customizable harness.

The project is currently in discovery and architecture design. Turborepo is selected for the monorepo and Vercel for production web deployment. Rodge Mail is the leading scaffold source and Convex the leading cloud-state candidate, but their exact reuse boundaries remain under evaluation.

## Vision

Interact with coding agents from the web, desktop, or phone while work executes on the most appropriate remote machine or isolated environment. The system should make orchestration, verification, resource allocation, and computer use explicit and customizable rather than hiding them behind a generic harness adapter.

## Project memory

UAV is the source of truth for project intent, decisions, architecture notes, and tasks. Use `uav status`, `uav ask`, `uav notes`, and `uav task list` from this repository.

Verbatim planning transcriptions are preserved under `docs/raw/`; they are source material rather than a parallel project-management system.
